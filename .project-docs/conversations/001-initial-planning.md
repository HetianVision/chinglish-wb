## 技术决策

### 1. 数据库选择：Supabase PostgreSQL
**原因**:
- 从一开始使用生产级数据库，避免后期迁移
- 自动生成 TypeScript 类型定义
- 内置 RLS（Row Level Security）
- 实时订阅功能
- 免费额度充足

### 2. UI 系统：完整的 shadcn/ui 主题系统
**原因**:
- 统一的设计系统和组件库
- 开箱即用的深浅色主题
- CSS 变量驱动，易于自定义
- 高质量、可访问性强的组件

### 3. 项目文档：.project-docs/ 专用文件夹
**原因**:
- 系统化记录开发过程
- 技术决策可追溯
- 便于项目交接和维护

## 设计系统规划

### 熊猫黑白配色主题
- 主色调：黑白灰（呼应熊猫 + 黑白名单主题）
- 错误色：#FF4D4F（Chinglish 标记）
- 成功色：#52C41A（正确表达）
- 警告色：#FA8C16
- 信息色：#1890FF

### 支持深浅色模式
- 浅色模式：白色背景 + 黑色文字
- 深色模式：黑色背景 + 白色文字
- 自动适配系统主题
